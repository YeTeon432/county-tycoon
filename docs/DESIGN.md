# 系统设计《我在县城当县长》

> PRD 定"做什么"，这里定"怎么算"。所有数值都是初版猜测，放进配置表（`assets/resources/config/*.json`），代码里不写死。
> 规模目标：首版 5 → 100 人；代码按几千人也跑得动来写。

---

## 1. 时间

- 一个 tick = 1 个游戏月 ≈ 现实 20 秒（`economy.json: secondsPerMonth`），可 1× / 2× / 暂停。
- 每月结算顺序固定（方便调试、复现）：
  1. 居民上班 → 发工资
  2. 居民消费 → 店铺营业额
  3. 交租、交税 → 财政
  4. 居民状态更新（心情、储蓄、年龄、婚姻、换工作、搬家、迁出）
  5. 迁入（外县来人）
  6. 每季度末：招商引资窗口开放
  7. 账单弹出 + 自动存档
- 一年 12 个月，居民每年长 1 岁（在生日那个月）。

## 2. 居民

### 2.1 档案
```ts
interface Resident {
  id: number;
  name: string;            // 姓 + 名，名字库按性别、年代挑
  gender: 'M' | 'F';
  age: number;
  birthMonth: number;      // 1..12
  homeId: number | null;   // 住哪栋（建筑 uid）
  jobId: number | null;    // 在哪上班（建筑 uid）
  jobTitle: string;        // 店员 / 车间工人 / 老师……
  salary: number;          // 月薪
  savings: number;
  spouseId: number | null;
  parentIds: number[];
  childIds: number[];
  mood: number;            // 0..100
  education: 0 | 1 | 2 | 3;// 无 / 中学 / 高中 / 大专以上
  monthsUnemployed: number;
  arrivedMonth: number;    // 什么时候来的县城
  vehicle: 'walk' | 'ebike' | 'moto' | 'car';  // 交通工具（第 11 节），开局都是 walk
  log: string[];           // 最近几条大事："3 月 入职纺织厂" "6 月 和 李秀兰结婚"
}
```

### 2.2 人生阶段
| 年龄 | 状态 | 做什么 |
|---|---|---|
| 0～5 | 幼儿 | 跟父母住，不消费（算进家庭开销） |
| 6～17 | 上学 | 附近有学校就上学（学历提升），没有学校家长心情 − |
| 18～59 | 劳动 | 找工作、消费、结婚、换房 |
| 60+ | 退休 | 领少量养老金（财政出），消费偏早餐铺、广场、卫生院 |
| 80+ | 每年有小概率离世 | 记一条日志，房子空出一个位置 |

### 2.3 每月的一天（按顺序）
1. **工作**：有工作 → 拿工资；没工作 → `monthsUnemployed++`，去找（2.4）。
2. **消费**：月可支配 = 工资 × 消费率（`spendRate` 约 0.5）+ 储蓄的一小部分。按"需求"分到附近的店：
   - 吃（早餐铺、火锅店、烧烤摊、超市）40%
   - 日用（超市、快递驿站）20%
   - 娱乐（奶茶店、网吧、广场）20%
   - 其他（理发店、手机店、补习班）20%
   - **"附近"= 从家沿道路走 8 格以内**，越近越优先；同类店多家时按距离和店铺口碑分。附近没有这类店，这部分钱存下来，但心情 −。
3. **交租**：租金 = 住宅基础租金 × 地价系数（M4 前恒为 1）。
4. **储蓄** = 收入 − 消费 − 租金 − 个税。
5. **心情**更新（0～100），影响因素：有没有工作、通勤距离、附近店铺是否齐全、住房是否拥挤、环境（树、广场 +，工厂矿场 −）、特色街道。

### 2.4 找工作
- 失业的人每月看一遍县城里所有招不满的岗位，挑 `工资 − 通勤距离 × 惩罚` 最高的，学历够才能去。
- 在职的人每年有小概率"跳槽"到工资高 20% 以上的地方。

### 2.5 成家
- 18～40 岁、单身、心情 > 50：每月小概率和同县另一位单身异性结婚（年龄差 ≤ 6）。
- 婚后住一起（搬进两人里条件好的那家，挤不下就找空房）。
- 已婚 22～40 岁、有储蓄、家里有空位：每年小概率生孩子。

### 2.6 换房 / 迁出
- 储蓄够、家里挤或心情低 → 找更好的空房搬过去。
- 迁出：心情 < 20 持续 3 个月，或失业 6 个月 → 全家搬离县城，日志记"因为找不到工作离开了"。

### 2.7 迁入（外县来人）
- 每月：如果"空岗位 > 0 且有空房"，按 `空岗位数 × 吸引力` 来人，吸引力看平均心情、特色街道、营商环境。
- 来的多是 20～35 岁单身或小两口，先进最便宜的空房。
- **开局特殊**：头几个月固定来几个人（一对老夫妻、一个回乡青年……），保证新手期有节奏。

## 3. 财政

| 收入 | 计算 |
|---|---|
| 营业税 | 店铺营业额 × 税率（默认 10%） |
| 企业税 | 工厂产值 × 税率（默认 15%） |
| 个人所得 | 工资超过起征点的部分 × 5% |
| 土地出让 | 每盖一栋私人建筑（店铺、工厂、商品房），按 地价 × 占地 一次性入账（M4） |
| 招商投资款 | 招商成功时一次性 |

| 支出 | 计算 |
|---|---|
| 建设 | 盖楼的钱 |
| 维护 | 每栋每月固定（道路很便宜，公共建筑贵） |
| 公共岗位工资 | 学校老师、卫生院、发展中心的人工资由财政发 |
| 养老金 | 60 岁以上每人每月少量 |
| 招商费 | 每次发起时 |

- 税率可调（滑条）：税高财政多，但居民心情 −、招商成功率 −。
- **不会失败**：财政可以短暂为负但不能盖新东西；连续为负时自动减少公共支出，不会游戏结束。

## 4. 建筑数据

每种建筑在 `buildings.json` 里增加：

```json
{
  "id": "breakfast",
  "cost": 3000,           // 建设费
  "upkeep": 50,           // 月维护
  "housing": 0,           // 能住几人
  "jobs": [{ "title": "店员", "count": 2, "salary": 2800, "edu": 0 }],
  "demand": "food",       // 满足哪类消费
  "capacity": 40,         // 每月最多服务多少人次
  "price": 15,            // 客单价
  "env": 0,               // 对周边环境的影响（树 +1，工厂 -3）
  "unlock": "village"     // 哪个城镇等级解锁
}
```

## 5. 招商引资

- 每季度末可发起一次，花招商费（随城镇等级涨）。
- **营商环境分**（0～100）= 道路覆盖 + 城市道路 + 港口 + 派出所 + 学历结构 + 可用劳动力 + 发展中心等级 − 税率惩罚。
- 成功率 = 营商环境 × 系数，封顶 85%。
- 结果按权重随机：
  | 结果 | 内容 |
  |---|---|
  | 工厂 | 免费送一座当前等级可用的工厂（玩家选位置） |
  | 品牌 | 送一家连锁店铺，口碑起点高 |
  | 投资款 | 财政 + 一笔钱 |
  | 人才 | 迁入几位高学历居民 |
  | 失败 | 只花了招商费，弹一句理由（"投资方嫌交通不方便"） |
- 失败理由要指向营商环境里最弱的那一项，告诉玩家下次该补什么。

## 6. 城镇等级

| 等级 | 人口 | 其他条件 |
|---|---|---|
| 村口 → 镇上 | 20 | 有 1 个工作岗位类建筑 |
| 镇上 → 县城 | 60 | 有学校、平均心情 ≥ 50 |
| 县城 → 县级市 | 150 | 有银行、营商环境 ≥ 50 |
| 县级市 → 百强县 | 500 | 后期 |

升级时：解锁建筑、可建区域扩大（过河、进山）、弹一段小剧情。

## 7. 地图（M4）

- 固定一张手工设计的开局地图（不做随机生成）：一条河从中间斜穿，一侧是开局平地，对岸是县城扩展区，远处山区有 2～3 个矿点，零散树林和池塘。
- 地块类型：草地、河（不能盖，只能放桥 / 港口靠边）、山（不能盖）、矿点（只能放矿场）、树林（可以砍，砍了环境 −）。
- 可建区域：按城镇等级解锁的若干块，没解锁的显示为灰雾。

## 8. 界面

### 8.1 内容
- **顶栏**：日期（X 年 X 月）、建设资金、人口、平均心情、速度按钮
- **点住宅**：住了几人 / 容量，住户名单（名字 + 年龄 + 工作），点名字 → 档案
- **点店铺 / 工厂**：员工名单、本月营业额、服务了多少人次、上交税款
- **居民总览**：列表，可按工作 / 年龄 / 收入 / 心情 排序筛选；顶部汇总（人口、就业率、平均工资、平均储蓄、有车率）
- **月度账单**：本月收支、人口变化、大事记（"王建国和李秀兰结婚了""张伟因为找不到工作离开了""赵培根买了一辆摩托车"）
- **点街上的行人 / 车**：小卡片显示他是谁、开的什么车

### 8.2 风格（D022，取代"半透明深底"）
- 明亮、干净，跟 3D 画面一个调性：**白色圆角卡片 + 柔和投影**，正文深灰 `#33363d`，次要文字 `#8a8f99`。
- 主色：草绿 `#4cae4c`（确定、正向数值）、天蓝 `#3a86d6`（信息、选中）、暖黄 `#f6c938`（资金、强调）、珊瑚红 `#e8574a`（警告、负数、拆除）。
- 圆角 16（卡片）/ 999（胶囊按钮），投影 0 4 12 rgba(0,0,0,0.15)。字号：标题 32、正文 26、辅助 22（720 宽设计分辨率）。
- **顶栏**：一排白色胶囊，每个胶囊 = 图标 + 数字（📅 2年3月 / 💰 ¥50,781 / 👥 5 / 😊 57）；速度、账单是右侧圆形图标按钮。
- **底栏（建造）**：上面一排类别页签（住宅 / 店铺 / 工业 / 公共 / 道路·设施），下面横向滚动的建筑卡片：缩略图（直接用建筑图集里那张图）+ 名字 + 价格；买不起的卡片变灰、价格变红；未解锁的显示锁和解锁条件。
- **面板**：从底部滑上来的白色抽屉（不是屏幕中间的深色框），顶部有拖动条，右上角关闭。
- **图标**：统一一套简单的扁平图标（PIL / SVG 程序化生成，放 `assets/resources/ui/`），不用 emoji 字体（各机型显示不一致）。
- 预览里左下角的帧率统计默认关掉（调试开关里能打开）。

## 10. 实现要点

- 模拟层纯数据、纯函数：`core/sim/`，不依赖引擎，能用 node 直接跑单元测试，可以"快进 100 年"看数值是否崩。
- 随机数用带种子的生成器：同一个存档、同一个种子，结果完全一样，方便复现 bug。
- 行人显示：从居民里按"正在通勤 / 去消费"的人抽样，最多显示 40 个；点行人能对应到真实居民。
- 存档只存居民数组 + 建筑数组 + 财政 + 时间 + 随机种子，几千人也就几百 KB。

## 11. 出行与交通工具（D022）

### 11.1 谁有车
- 开局全员 `walk`。每月结算第 4 步（居民状态更新）里，对每个 18～65 岁、有工作、还没有更好交通工具的人判断一次「买车」：
  | 交通工具 | 前提 | 价格 | 买的条件 | 每月概率 |
  |---|---|---|---|---|
  | 电动车 ebike | 县里有 ≥1 座摩托车厂 | 3,000 | 储蓄 ≥ 价格 × 1.5 | 1.5% |
  | 摩托车 moto | 同上 | 8,000 | 储蓄 ≥ 价格 × 1.5，月薪 ≥ 3,000 | 1% |
  | 汽车 car | 县里有 ≥1 座汽车厂 | 40,000 | 储蓄 ≥ 价格 × 1.2，月薪 ≥ 4,500 | 0.8% |
- 只往上换（步行 → 电动车 → 摩托车 → 汽车）；同时满足几档时直接买最好的那档，旧车不回收。
- 买车的钱：从储蓄扣，算进**最近一座对应工厂的产值**（企业税照常收）。记一条大事记。
- 厂全拆了：已有的车照开，只是没人能再买。
- 汽车每月油费 300（从可支配收入里扣，不进财政）；电动车、摩托车不计。
- 数值全在 `economy.json: vehicles`。
- 调参依据（支线 A 30 年快进，2026-11-14）：最初 8% / 5% / 3%、汽车 6 万时，盖摩托车厂 1 年有车率就到 45%、3 年 75%，而汽车 30 年一辆没卖出（储蓄平衡点约 6 万，够不着 7.2 万门槛）。调成上表后：第 1 年盖摩托车厂，1 年 8%、4 年 35%、10 年 44%、30 年 72%；汽车只有技术岗买得起，县里没学校时 30 年 7～14 辆。

### 11.2 车对模拟的影响
- 消费半径 = `serviceRadius` × 交通倍率：步行 1.0、电动车 1.5、摩托车 1.7、汽车 2.2。上班找工作的距离同理。
- 通勤惩罚 `commutePenalty` × （1 / 交通倍率）。
- 有车的人心情 +3（汽车 +5），一次性体现在每月心情目标里。

### 11.3 街上的表现（LifeLayer）
- 街上每个移动的东西都是一位居民：没车的走路，有车的按自己的车出现。**不再有匿名汽车**。
- 抽样比例：有车的居民出门时 70% 开车、30% 步行（短途也会走路）。
- 速度（格 / 秒，`config/traffic.json`）：
  | | 基础速度 | 土路倍率 | 城市道路倍率 | 桥 |
  |---|---|---|---|---|
  | 步行 | 0.6 | 1.0 | 1.0 | 1.0 |
  | 电动车 | 1.3 | 0.8 | 1.0 | 1.0 |
  | 摩托车 | 1.7 | 0.75 | 1.0 | 1.0 |
  | 汽车 | 2.2 | 0.45 | 1.0 | 1.0 |
  每人在基础速度上有 ±10% 的个人差异（按居民 id 固定，不每次随机）。在一格里按当前格的道路类型取倍率。
- 汽车现在也能开上土路（很慢），不再只走城市道路——修城市道路的意义就是「车跑得快 + 营商环境」。
- 图：电动车、摩托车、汽车各 3 种颜色；同一个人每次都是同一辆车（按 id 选颜色）。

## 12. 放置建筑（D022，修 D015 的朝向问题）
- 状态机：`空闲` →（底栏选建筑）→ `已选` →（点地块）→ `预览` →（确定）→ 盖下，回到 `已选`（方便连续盖同一种）；`预览` 里点别的地块 = 挪预览；点「取消」或底栏再点一次 = 回 `空闲`。
- 预览用真实贴图半透明显示，默认朝向按 D015 的规则（左下挨路 → L，右下挨路 → R，否则 L）；「换朝向」在 L/R 间切；没有 `_r` 图的建筑按钮灰掉。
- 放不下（重叠、越界、地形不许、钱不够）：预览染红，「确定」灰掉，下方一行小字说原因。
- 确定时把朝向一起交给 `TownModel.place(def, col, row, facing)`，直接锁定，不再等「第一次挨上路」。
- 道路（`flat`）跳过预览：点一下就铺，在 `已选` 状态下可以连续点。
- 浮动按钮跟着预览走，放在预览上方；靠屏幕边时自动挪到能看见的一侧。

## 13. 开局（D022）
- 开局资金 `economy.json: startFunds`，默认 **100,000**（原 50,000；开局要修路 + 盖店，5 万太紧）。
- 新档才播开场；读档直接进游戏。开场 3 张白卡片，点任意处翻页，右上「跳过」：
  1. 「在外打拼多年，你回到了老家。」
