# 《我在县城当县长》音效 PRD

**版本**　2026-11-21 Web 横屏试玩版。首版包含 8 条操作与经营音效，以及一首默认开启的循环背景音乐。

## 1. 玩家应该听懂什么

玩家照着乡亲的心愿盖一家早餐铺。挪动预览时，留给玩家安静选址的时间。按下「确定」、工地出现时，响一记落锤。几天后店铺完工，换成明亮的收尾音。如果同一刻居民也达成了心愿，优先让玩家听到心愿兑现的两枚暖音，公告里仍能看到两件事。

声音要像在小县城里做事。常用操作取木块、泥土和纸张的短促质感，值得高兴的事才加旋律。失败提示要让人停下来看看原因，音量轻于落锤。普通手机外放、低音量或单声道下，开工、受阻和心愿达成也应靠节奏和音色区分。

## 2. 首版声音清单

每行对应一条可独立试听的声音。时长是首轮打样目标。操作音跟随本次操作的实际结果，经营事件音跟随当批新产生、且已向玩家展示的结果。

| 优先级 / 素材 | 玩家何时听到 | 听感与打样时长 |
|---|---|---|
| P0 · 轻点 | 打开居民档案、切换建造分类、切换时间档位或取消选址，界面确实发生变化时一次 | 木片轻碰，约 70 毫秒，所有声音里最轻 |
| P0 · 铺路 | 一格土路或城市道路铺设成功，或土路成功升级后 | 短促的砂石压实声，约 120 毫秒，连铺仍能听清节奏 |
| P0 · 开工 | 建筑选址确认成功、地图出现工地时。自建店铺、分厂和招商交地共用 | 一记偏低的木槌，约 180 毫秒，尾音收干 |
| P0 · 受阻 | 玩家提交可操作的指令，游戏返回资金不足、位置冲突等原因时 | 两下低而钝的轻敲，约 180 毫秒，与画面上的原因同时出现 |
| P0 · 拆除 | 选中目标并确认，目标实际移除时 | 短碎石滑落声，约 220 毫秒 |
| P0 · 完工 | 施工结束，建筑首次从工地变成可用建筑时 | 清亮的一敲加短尾音，约 300 毫秒 |
| P0 · 心愿达成 | 居民实际入职或所需服务到位，游戏确认心愿完成时 | 柔和的两音上行，约 450 毫秒 |
| P0 · 城镇晋升 | 玩家成功晋升，新阶段庆祝卡首次出现时 | 三音短乐句，约 900 毫秒。最高荣誉留给城镇跨阶段 |
| P1 · 引起关注 | 有居民首次进入挽留期，或出现迁出公示时 | 两个间隔较开的低音，约 350 毫秒 |
| P1 · 欢迎 | 新居民迁入公示首次出现时。批量人才引进共用一次 | 轻快的门铃声，约 350 毫秒 |
| P1 · 经营进展 | 研究完成、招商签约成功或首次成街的结果展示时 | 一声印章落纸加短亮音，约 300 毫秒 |

P0 为首版交付的 8 条。P1 排在核心操作试听通过之后。配音和持续环境声留待后续。日常行走、逐笔消费、资金滚动、自动月结和普通公告轮播保持安静。玩家可从地图、账单和公告查看相应信息。

## 3. 同时发生几件事时怎么播

- **一次操作只给一个结果音。** 确认建造就播落锤，省去通用轻点。点灰色「确定」、拖动红色预览、在地图上平移或捏合都保持安静。取消拆除可播轻点。
- **批量结算只选一声。** 同一批结算按「城镇晋升 → 居民需关注 → 心愿达成 → 经营进展 → 完工 → 欢迎」选首个已接入且可展示的事件。只在对应结果首次呈现时播，其余结果照常显示。再次打开档案、账单或历史公告，只允许本次打开界面的轻点。
- **给主动操作留位置。** 连铺路每 120 毫秒最多响一次，连续受阻每 500 毫秒最多响一次。自动事件之间至少间隔 2 秒，期间的新事件静默展示，晋升可覆盖正在播的自动事件。同一时刻最多保留一个操作音和一个事件音，按现实时间计时。×2、×3 只加快模拟。
- **玩家能随时收声。** 将现有「地图设置」面板标题改为「设置」，在「常显地图网格」旁增加「游戏音效」开关，显示「已开启 / 已关闭」。默认开启。关闭时立即停止全部音效，音乐沿用自己的开关状态，开启时播一次轻点供试听。偏好按设备当前浏览器保存，刷新、继续旧档和重新开局都沿用。公告喇叭仍用于查看消息。
- **打开、暂停与离开。** 加载页静默。首次有效点击或触摸后才允许发声，之前的事件直接略过。模拟暂停期间，设置和面板仍响应操作音。切后台立即停声，回前台沿用开关状态，只响应新事件。音频加载或播放失败时，保留文字、公示和操作结果，照常进入游戏。

## 4. 默认背景音乐《塘边早市》

玩家首次点进游戏时，拨弦旋律从村口响起，中段由柔和的簧管音色接过，再回到开头。原创主题为 D 大调、每分钟 92 拍、24 小节，约 63 秒循环一次。音乐放在落锤、完工和心愿提示的下方。浏览地图、打开面板、模拟暂停和倍速时维持原速。

「设置 → 背景音乐」默认开启，与「游戏音效」分别保存。关音乐时暂停该曲，重新开启时从原处继续。切后台时两者都安静，返回时按偏好继续音乐。玩家关掉两项后，刷新、读档或新开局都保持安静。

## 5. 交付和验收

本版音乐与音效由项目原创合成，全部旋律、音色和节奏保存在[音频生成脚本](audio/render.py)，可重新导出。八个短音依清单顺序为 tap、road、build、blocked、remove、complete、wish、promote，背景音乐为 town-theme。验收时按下列场景在真正的游戏流程里听。

| 场景 | 通过条件 |
|---|---|
| 新档加载后选早餐铺，拖过无效位置再确认有效位置 | 加载、拖动、灰色确认都无声。有效确认只响一次落锤，建筑可用时才有完工反馈。 |
| 选中建筑取消拆除，再次选中并确认 | 首次保留建筑且无碎石声，第二次建筑消失时只响一次碎石。 |
| 连铺 10 格，再连续尝试被拒的操作 | 成功与受阻可听辨，两者分别遵守 120 / 500 毫秒间隔。被拒时有可读的原因。 |
| 同批完工并满足多位居民的心愿，随后翻阅公告 | 本批只听到一次心愿音。所有结果可在界面核对，翻历史时不重播。 |
| 发展中心晋升，退出后再次进入 | 新阶段庆祝卡第一次出现时播放完整短句，再次进入只有界面操作反馈。 |
| 切到 ×3 观察一个结算月，再暂停打开居民档案 | 音高、音长与常速一致。暂停后打开档案仍有轻点。 |
| 分别关闭音乐、音效，再刷新、切到后台并返回 | 两个开关独立记住。关音效后音乐可继续，关音乐后操作可发声。重开音效响一次轻点。后台两者均安静，返回后无积压提示音。 |
| 听过一个完整乐段，再切换倍速并反复切回游戏 | 乐曲自然回到第一小节，只有一轨，音高与速度稳定。 |
| 静音或音频资源请求失败，再完成一次建造 | 仍可仅凭红绿预览、资金变化、工地和公告判断结果，进入游戏和存档均正常。 |

手机外放试听重点为落锤与完工是否好区分、主题循环接缝是否自然、音乐是否掩盖操作。迁入与挽留提示列入 P1。
