# PRD v0.4 《我在县城当县长》

> 2026-11-14 v0.4：加交通工具与出行、放置时选朝向、开局启动资金、界面改版（D022）。

> 2026-11-13 由 v0.2《我在县城当首富》改版（D018）：玩家从"开店的个人"改为"县城的管理者"。
> 详细规则和数值见 `docs/DESIGN.md`。数值都是初始猜测，做原型时再调。

## 1. 一句话定位
竖屏单机像素城镇经营：玩家接手一个只有 5 口人的小地方，修路盖房、建厂开店、招商引资，让每一个有名有姓的居民过上好日子，把它从无名小村发展成全省百强县。

## 2. 开局（30 秒以内，可跳过）
大城市工作多年的主角回到老家，接手县城的发展工作。开局只有河边一小块地、一条土路、两栋自建房、5 位居民，和一笔启动资金。

- 开场 3 张卡片（可跳过）：回到老家 → 带来启动资金（大字显示金额，默认 ¥100,000，配置表可改）→ 「先修条路、盖几家店，让大家有活干」。
- 关掉卡片后，资金从 0 滚到启动金额，顶栏资金闪一下；接着出一条新手提示指向底栏。
- 启动资金是县城的「建设资金」，界面上不说是谁拨的（避开政府用词）。

## 3. 核心循环
1. **建设**：花建设资金修路、盖住宅、店铺、工厂、公共建筑
2. **居民生活**：每个居民每月上班领工资、去附近的店消费、交租，过得好就留下、成家，过得不好就搬走
3. **财政**：店铺、工厂、居民收入按税率进财政；财政再拿去建设
4. **招商引资**：每季度一次，按营商环境有概率引来工厂、品牌、投资；新岗位吸引外县居民迁入
5. **成长**：人口和发展度达标 → 城镇升级 → 解锁新建筑、新地块（过河、进山）

## 4. 目标与阶段
| 阶段 | 人口 | 解锁（大致） |
|---|---|---|
| 村口 | 5～20 | 土路、自建房、早餐铺、小卖部类店铺 |
| 镇上 | 20～60 | 工厂（小）、学校、超市、招商引资 |
| 县城 | 60～150 | 城市道路、商品房、银行、桥（过河） |
| 县级市 | 150～500 | 港口、矿场、学区房、火锅店 |
| 百强县 | 500+ | 后期内容 |

首版目标：**从 5 人发展到 100 人左右**，一局大约 1～2 小时。人口几千是长线内容，不急。

## 4.5 画面
- 等距视角（2:1 菱形地块），建筑有亮暗面、招牌和门窗细节；街上有行人和车辆（D014）。街上的行人是真实居民，点一下能看到是谁。
- 所有美术原创，不使用任何已有游戏的素材、角色或界面样式。

## 5. 建筑
### 5.1 已有（15 种 + 装饰）
| 类别 | 建筑 | 尺寸 | 说明 |
|---|---|---|---|
| 住宅 | 自建房 | 1×1 | 住 4 人，便宜 |
| 住宅 | 商品房小区 | 2×2 | 住 20 人 |
| 住宅 | 学区房 | 2×2 | 住 12 人，贵，附近有学校/补习班时更抢手 |
| 店铺 | 早餐铺 / 奶茶店 / 烧烤摊 / 快递驿站 / 网吧 / 手机店 / 理发店 / 补习班 | 1×1 | 提供少量岗位，满足居民消费 |
| 店铺 | 火锅店 / 超市 | 2×2 | 岗位多一些，消费大 |
| 设施 | 道路·土路 | 1×1 | 开局就有，便宜。建筑要挨着道路才能营业 |
| 设施 | 道路·城市道路 | 1×1 | 「县城」解锁，车走得更快，提升营商环境 |
| 设施 | 广场 | 2×2 | 提升周边居民心情 |
| 装饰 | 行道树 | 1×1 | 提升一点周边环境 |

### 5.2 新增（DESIGN.md 第 4 节）
- **岗位类**：小作坊 → 纺织厂 / 食品厂 / 电子厂（污染）；**摩托车厂**（镇上）、**汽车厂**（县城）——除了岗位，还让居民能买到车（6.5）
- **公共类**：县政务中心（"发展中心"）、学校、卫生院、派出所
- **金融**：银行（居民储蓄、建设贷款）
- **地形相关**：桥、港口、矿场

道路规则：土路和城市道路统称「道路」，规则里说"挨着道路"时两种都算；土路可以原地升级成城市道路。

## 6. 特色街道（5 种）
同一条道路边上、互相相邻的建筑满足组合时触发，效果改为作用在居民和店铺上：

| 街道 | 组合 | 效果 |
|---|---|---|
| 夜市一条街 | 烧烤摊 + 奶茶店 + 火锅店 | 周边居民夜间消费 +50% |
| 便民生活圈 | 早餐铺 + 超市 + 快递驿站 | 周边居民心情 +，搬走率降低 |
| 学区 | 学区房 + 补习班 + 早餐铺 | 学区房更抢手，地价上涨 |
| 网红打卡街 | 奶茶店 + 理发店 + 手机店 | 外县年轻人迁入意愿提高 |
| 青年街 | 网吧 + 烧烤摊 + 奶茶店 | 店铺营业额 +30% |

## 6.5 出行与交通工具
- 开局所有人**步行**，街上只有行人。
- 盖了 **摩托车厂** 之后，有钱的居民会买电动车 / 摩托车；盖了 **汽车厂** 之后，有钱的居民会买汽车。每人最多一辆，档案里能看到「交通：步行 / 电动车 / 摩托车 / 汽车」。
- 街上的电动车、摩托车、汽车**都是真实居民在开**，点了能看到是谁；没人有车就没有车。
- 有车的人能去更远的店消费、上更远的班，心情也会好一点；汽车每月要花油钱。
- 不同交通工具速度不同（步行最慢，汽车最快）；城市道路比土路快，汽车在土路上明显变慢。

## 6.6 放置建筑
- 选好建筑后，点地块先出现**半透明预览**（真实图，不是色块），旁边浮出三个按钮：**换朝向 / 确定 / 取消**。点别的地块预览就挪过去，确认后才扣钱盖下。
- 预览的默认朝向按旁边的路自动选（门面对着路）；玩家可以先换朝向再确定。放不下时预览变红，「确定」变灰。
- 道路不需要确认：点一下就铺，可以连续点。
- 盖好以后，点建筑打开详情，里面仍然可以换朝向。

## 7. 系统
- **居民**：每人一张档案（姓名、年龄、性别、婚姻、家庭、住址、工作、工资、储蓄、心情），每月过一次日子（DESIGN.md 第 2 节）
- **居民总览**：可筛选、排序；点建筑看住户 / 员工名单
- **财政**：税收 + 土地出让 − 建设 − 维护；每月一张账单
- **招商引资**：每季度一次，成功率看营商环境
- **城镇等级**：按人口和发展度
- **店铺升级**、**地价**：M4 做
- **时间**：1 个游戏月 ≈ 现实 20 秒（原型再调），可 2 倍速
- **存档**：本地存储，每月自动存；离线收益后期再说
- **界面风格**：明亮、圆角白卡片，配色和 3D 画面一致（不再是深色半透明底）；底栏按类别分页，每个建筑一张带缩略图和价格的卡片（DESIGN 第 8 节）
- **不会失败**：财政不会变负数到"游戏结束"，最差是钱少、人走
