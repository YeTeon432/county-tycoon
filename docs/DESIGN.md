# 系统设计《我在县城当县长》

> PRD 定"做什么"，这里定"怎么算"。所有数值都是初版猜测，放进配置表（`assets/resources/config/*.json`），代码里不写死。
> 规模目标：首版 5 → 100 人；代码按几千人也跑得动来写。

---

## 1. 时间

- 一个 tick = 1 个游戏月 = 画面上的一天 ≈ 现实 60 秒（`economy.json: secondsPerMonth`，D025 由 20 秒改为 60 秒），可 1× / 2× / 3× / 暂停（快进按钮点一下换一档，右下角角标显示 ×2 / ×3）。1 倍速一年 12 分钟，2 倍速 6 分钟，3 倍速 4 分钟。
- 每月结算顺序固定（方便调试、复现）：
  1. 居民上班 → 发工资
  2. 居民消费 → 店铺营业额
  3. 交租、交税 → 财政
  4. 居民状态更新（心情、储蓄、年龄、婚姻、换工作、搬家、迁出）
  5. 迁入（外县来人）
  6. 每季度末：招商引资窗口开放
  7. 账单弹出 + 自动存档
- 一年 12 个月，居民每年长 1 岁（在生日那个月）。

## 2. 居民

### 2.1 档案
```ts
interface Resident {
  id: number;
  name: string;            // 姓 + 名，名字库按性别、年代挑
  gender: 'M' | 'F';
  age: number;
  birthMonth: number;      // 1..12
  homeId: number | null;   // 住哪栋（建筑 uid）
  jobId: number | null;    // 在哪上班（建筑 uid）
  jobTitle: string;        // 店员 / 车间工人 / 老师……
  salary: number;          // 月薪
  savings: number;
  spouseId: number | null;
  parentIds: number[];
  childIds: number[];
  mood: number;            // 0..100
  education: 0 | 1 | 2 | 3;// 无 / 中学 / 高中 / 大专以上
  monthsUnemployed: number;
  arrivedMonth: number;    // 什么时候来的县城
  vehicle: 'walk' | 'ebike' | 'moto' | 'car';  // 交通工具（第 11 节），开局都是 walk
  log: string[];           // 最近几条大事："3 月 入职纺织厂" "6 月 和 李秀兰结婚"
}
```

### 2.2 人生阶段
| 年龄 | 状态 | 做什么 |
|---|---|---|
| 0～5 | 幼儿 | 跟父母住，不消费（算进家庭开销） |
| 6～17 | 上学 | 附近有学校就上学（学历提升），没有学校家长心情 − |
| 18～59 | 劳动 | 找工作、消费、结婚、换房 |
| 60+ | 退休 | 领少量养老金（财政出），消费偏早餐铺、广场、卫生院 |
| 80+ | 每年有小概率离世 | 记一条日志，房子空出一个位置 |

### 2.3 每月的一天（按顺序）
1. **工作**：有工作 → 拿工资；没工作 → `monthsUnemployed++`，去找（2.4）。
2. **消费**：月可支配 = 工资 × 消费率（`spendRate` 约 0.5）+ 储蓄的一小部分。按"需求"分到附近的店：
   - 吃（早餐铺、火锅店、烧烤摊、超市）40%
   - 日用（超市、快递驿站）20%
   - 娱乐（奶茶店、网吧、广场）20%
   - 其他（理发店、手机店、补习班）20%
   - **"附近"= 从家沿道路走到这家店的辐射半径以内**（每种店不同，D035：近邻店 5～6、街区店 8～10、片区店 14），越近越优先；同类店多家时按距离和店铺口碑分。附近没有这类店，这部分钱存下来，但心情 −。
3. **交租**：租金 = 住宅基础租金 × 地价系数（M4 前恒为 1）。
4. **储蓄** = 收入 − 消费 − 租金 − 个税。
5. **心情**更新（0～100），影响因素：有没有工作、通勤距离、附近店铺是否齐全、住房是否拥挤、环境（树、广场 +，工厂矿场 −）、特色街道。

### 2.4 找工作
- **赋闲**（D024）：劳动年龄、没工作，且存款 ≥ `idleSavingsMonths`（12）×（房租 + `idleLivingCost` 1000）的人不找工作，记 `idle = true`：不算失业（`monthsUnemployed` 不涨、不会因失业搬走），心情 + `idleMood`（4）。存款跌到门槛 × `idleExitRatio`（0.5）以下才重新找工作。**已经有工作的人不会因为有钱辞职。** 参数在 `economy.json: tuning.residents`。
- 失业的人每月看一遍县城里所有招不满的岗位，挑 `工资 − 通勤距离 × 惩罚` 最高的，学历够才能去。
- 在职的人每年有小概率"跳槽"到工资高 20% 以上的地方。

### 2.5 成家
- 18～40 岁、单身、心情 > 50：每月小概率和同县另一位单身异性结婚（年龄差 ≤ 6）。
- 婚后住一起（搬进两人里条件好的那家，挤不下就找空房）。
- 已婚 22～40 岁、有储蓄、家里有空位：每年小概率生孩子。

### 2.6 换房 / 迁出
- 储蓄够、家里挤或心情低 → 找更好的空房搬过去。
- 迁出：心情 < 20 持续 3 个月，或失业 6 个月 → 全家搬离县城，日志记"因为找不到工作离开了"。

### 2.7 迁入（外县来人）
- 每月：如果"空岗位 > 0 且有空房"，按 `空岗位数 × 吸引力` 来人，吸引力看平均心情、特色街道、营商环境。
- 来的多是 20～35 岁单身或小两口，先进最便宜的空房。
- **开局特殊**：头几个月固定来几个人（一对老夫妻、一个回乡青年……），保证新手期有节奏。

## 3. 财政

| 收入 | 计算 |
|---|---|
| 营业税 | 店铺营业额 × 税率（默认 10%） |
| 企业税 | 工厂产值 × 税率（默认 15%） |
| 个人所得 | 工资超过起征点的部分 × 5% |
| 土地出让 | 每盖一栋私人建筑（店铺、工厂、商品房），按 地价 × 占地 一次性入账（M4） |
| 招商投资款 | 招商成功时一次性 |

| 支出 | 计算 |
|---|---|
| 建设 | 盖楼的钱 |
| 维护 | 每栋每月固定（道路很便宜，公共建筑贵） |
| 公共岗位工资 | 学校老师、卫生院、发展中心的人工资由财政发 |
| 养老金 | 60 岁以上每人每月少量 |
| 招商费 | 每次发起时 |

- 税率可调（滑条）：税高财政多，但居民心情 −、招商成功率 −。
- **不会失败**：财政可以短暂为负但不能盖新东西；连续为负时自动减少公共支出，不会游戏结束。

## 5. 招商引资

> ⚠️ 本节被第 20 节（D026）取代，保留作历史。

- 每季度末可发起一次，花招商费（随城镇等级涨）。
- **营商环境分**（0～100）= 道路覆盖 + 城市道路 + 港口 + 派出所 + 学历结构 + 可用劳动力 + 发展中心等级 − 税率惩罚。
- 成功率 = 营商环境 × 系数，封顶 85%。
- 结果按权重随机：
  | 结果 | 内容 |
  |---|---|
  | 工厂 | 免费送一座当前等级可用的工厂（玩家选位置） |
  | 品牌 | 送一家连锁店铺，口碑起点高 |
  | 投资款 | 财政 + 一笔钱 |
  | 人才 | 迁入几位高学历居民 |
  | 失败 | 只花了招商费，弹一句理由（"投资方嫌交通不方便"） |
- 失败理由要指向营商环境里最弱的那一项，告诉玩家下次该补什么。

## 6. 城镇等级

| 等级 | 人口 | 其他条件 |
|---|---|---|
| 村口 → 镇上 | 20 | 有 1 个工作岗位类建筑 |
| 镇上 → 县城 | 60 | 有学校、平均心情 ≥ 50 |
| 县城 → 县级市 | 150 | 有银行、营商环境 ≥ 50 |
| 县级市 → 百强县 | 500 | 后期 |

升级时：解锁建筑、可建区域扩大（过河、进山）、弹一段小剧情。

## 7. 地图（M4）

- 固定一张手工设计的开局地图（不做随机生成）：一条河从中间斜穿，一侧是开局平地，对岸是县城扩展区，远处山区有 2～3 个矿点，零散树林和池塘。
- 地块类型：草地、河（不能盖，只能放桥 / 港口靠边）、山（不能盖）、矿点（只能放矿场）、树林（可以砍，砍了环境 −）。
- 可建区域：按城镇等级解锁的若干块，没解锁的显示为灰雾。

## 8. 界面

### 8.1 内容
- **顶栏**：日期（X 年 X 月）、建设资金、人口、平均心情、速度按钮
- **点住宅**：住了几人 / 容量，住户名单（名字 + 年龄 + 工作），点名字 → 档案
- **点店铺 / 工厂**：员工名单、本月营业额、服务了多少人次、上交税款
- **居民总览**：列表，可按工作 / 年龄 / 收入 / 心情 排序筛选；顶部汇总（人口、就业率、平均工资、平均储蓄、有车率）
- **月度账单**：本月收支、人口变化、大事记（"王建国和李秀兰结婚了""张伟因为找不到工作离开了""赵培根买了一辆摩托车"）
- **点街上的行人 / 车**：小卡片显示他是谁、开的什么车

### 8.2 风格（D039）
- 地图上的工具台用浅麦色 `#f0d4a7` 搭配陶砖橙 `#a34e29`，按钮用清晰的边缘和短投影表现层次。详情抽屉用暖白纸面 `#fffaee`，标题 32、正文 26、辅助 22（720 宽设计分辨率）。
- **顶栏**汇总日期和钟点、建设资金、居民数与幸福度。第二排显示发展目标进度、账单、暂停与当前倍速。升级就绪或招商待交地时，发展入口显示对应状态。就业率和平均工资在居民总览中查看。
- **底栏**上排放五类建造工具和拆除，下排是可横滑的建筑卡片。每张卡显示缩略图、名字和价格，选中页签用陶砖橙，选中建筑用暖黄，未解锁用锁标记。买不起或未解锁时仍可选中并看预览，确认按钮禁用并说明原因。建造、拆除和环境提示出现在工具栏上方，空闲时收起。

## 10. 实现要点

- 模拟层纯数据、纯函数：`core/sim/`，不依赖引擎，能用 node 直接跑单元测试，可以"快进 100 年"看数值是否崩。
- 随机数用带种子的生成器：同一个存档、同一个种子，结果完全一样，方便复现 bug。
- 行人显示：按一天的日程（第 15 节）只画「此刻在路上」的居民，最多 `maxOnStreet`（60）个；行人不能点（T424），被追踪的人不受 60 个的上限（T425）。
- 存档只存居民数组 + 建筑数组 + 财政 + 时间 + 随机种子，几千人也就几百 KB。

## 11. 出行与交通工具（D022）

### 11.1 谁有车
- 开局全员 `walk`。每月结算第 4 步（居民状态更新）里，对每个 18～65 岁、有工作、还没有更好交通工具的人判断一次「买车」：
  | 交通工具 | 前提 | 价格 | 买的条件 | 每月概率 |
  |---|---|---|---|---|
  | 电动车 ebike | 县里有 ≥1 座摩托车厂 | 3,000 | 储蓄 ≥ 价格 × 1.5 | 1.5% |
  | 摩托车 moto | 同上 | 8,000 | 储蓄 ≥ 价格 × 1.5，月薪 ≥ 3,000 | 1% |
  | 汽车 car | 县里有 ≥1 座汽车厂 | 40,000 | 储蓄 ≥ 价格 × 1.2，月薪 ≥ 4,500 | 0.8% |
- 只往上换（步行 → 电动车 → 摩托车 → 汽车）；同时满足几档时直接买最好的那档，旧车不回收。
- 买车的钱：从储蓄扣，算进**最近一座对应工厂的产值**（企业税照常收）。记一条大事记。
- 厂全拆了：已有的车照开，只是没人能再买。
- 汽车每月油费 300（从可支配收入里扣，不进财政）；电动车、摩托车不计。
- 数值全在 `economy.json: vehicles`。
- 调参依据（支线 A 30 年快进，2026-11-14）：最初 8% / 5% / 3%、汽车 6 万时，盖摩托车厂 1 年有车率就到 45%、3 年 75%，而汽车 30 年一辆没卖出（储蓄平衡点约 6 万，够不着 7.2 万门槛）。调成上表后：第 1 年盖摩托车厂，1 年 8%、4 年 35%、10 年 44%、30 年 72%；汽车只有技术岗买得起，县里没学校时 30 年 7～14 辆。

### 11.2 车对模拟的影响
- 消费半径 = 这家店的 `radius`（没写用 `serviceRadius` 8）× 交通倍率：步行 1.0、电动车 1.5、摩托车 1.7、汽车 2.2。上班找工作的距离同理。
- 通勤惩罚 `commutePenalty` × （1 / 交通倍率）。
- 有车的人心情 +3（汽车 +5），一次性体现在每月心情目标里。

### 11.3 街上的表现（LifeLayer）
- 街上每个移动的东西都是一位居民：没车的走路，有车的按自己的车出现。**不再有匿名汽车**。
- 抽样比例：有车的居民出门时 70% 开车、30% 步行（短途也会走路）。
- 速度（格 / 秒，`config/traffic.json`）：
  | | 基础速度 | 土路倍率 | 城市道路倍率 | 桥 |
  |---|---|---|---|---|
  | 步行 | 0.6 | 1.0 | 1.0 | 1.0 |
  | 电动车 | 1.3 | 0.8 | 1.0 | 1.0 |
  | 摩托车 | 1.7 | 0.75 | 1.0 | 1.0 |
  | 汽车 | 2.2 | 0.45 | 1.0 | 1.0 |
  每人在基础速度上有 ±10% 的个人差异（按居民 id 固定，不每次随机）。在一格里按当前格的道路类型取倍率。
- 汽车现在也能开上土路（很慢），不再只走城市道路——修城市道路的意义就是「车跑得快 + 营商环境」。
- 图：电动车、摩托车、汽车各 3 种颜色；同一个人每次都是同一辆车（按 id 选颜色）。

## 12. 放置建筑（D022，修 D015 的朝向问题）
- 状态机：`空闲` →（底栏选建筑）→ `已选` →（点地块）→ `预览` →（确定）→ 盖下，回到 `已选`（方便连续盖同一种）；`预览` 里点别的地块 = 挪预览；点「取消」或底栏再点一次 = 回 `空闲`。
- 预览用真实贴图半透明显示，默认朝向按 D015 的规则（左下挨路 → L，右下挨路 → R，否则 L）；「换朝向」在 L/R 间切；没有 `_r` 图的建筑按钮灰掉。
- 放不下（重叠、越界、地形不许、钱不够）：预览染红，「确定」灰掉，下方一行小字说原因。
- 确定时把朝向一起交给 `TownModel.place(def, col, row, facing)`，直接锁定，不再等「第一次挨上路」。
- 道路（`flat`）跳过预览：点一下就铺，在 `已选` 状态下可以连续点。
- 浮动按钮跟着预览走，放在预览上方；靠屏幕边时自动挪到能看见的一侧。
- **覆盖范围**（T538）：预览店 / 学校 / 卫生院 / 派出所 / 广场时，从预览的门口沿路走 N 格以内的路铺浅蓝，范围内的住宅脚下描黄框；顶栏提示「沿路 N 格内（蓝色）能服务 X 栋住宅（黄框）」。N：店 = 这家店自己的 `radius`（D035，步行，有车的居民更远，提示里说一句），学校 10、卫生院 8、派出所 10、广场 6（和幸福度、心愿用同一组常量）。预览不挨路 → 不画，提示「这里不挨路，居民走不过来」。

## 14. 居民样貌（D023）

### 14.1 问题（2026-11-14 盘点）
- 街上只有 6 套外观：女性只有 1 套（马尾），老人只有 1 套（老爷爷），**没有小孩、没有老奶奶**；女性映射里还混着两套男性发型。5 岁小孩、70 岁奶奶上街都长成青年人的样子。
- 居民档案只有一个写着姓的色块，看不出是谁。

### 14.2 规则
- 一个人的样子由 **体型 + 外观编号** 决定，都从档案算出来，纯函数（`core/Appearance.ts`），不存档：
  | 体型 | 条件 | 外观数 |
  |---|---|---|
  | boy 男孩 / girl 女孩 | 0～17 岁 | 各 2 |
  | man 成年男 / woman 成年女 | 18～59 岁 | 各 3 |
  | oldman 老爷爷 / oldwoman 老奶奶 | 60 岁以上 | 各 2 |
  外观编号 = 按居民 id 哈希取模，同一个人一辈子在同一体型里永远是同一套；长大、变老时换体型，样子跟着变（档案和街上一起变）。
- 共 14 套外观，皮肤名 `<体型><编号>`，例如 `woman1`、`oldman0`。每套有固定的发型、发色、上衣、裤子、鞋子：
  - 小孩矮一截（约成人 0.75），头身比更大，背书包（男孩）或扎两个小辫（女孩）。
  - 青壮男：短发 / 偏分 / 寸头；青壮女：马尾 / 齐肩短发 / 长直发。
  - 老爷爷：灰白稀疏 + 拄拐 / 光头 + 老头衫；老奶奶：灰白短卷 + 碎花衫 / 灰发盘髻 + 开衫。
- **街上** `<皮肤>-front0/front1/back0/back1`（14 × 4 = 56 帧，大小不变）；骑车的人沿用 3 套骑手外观（头盔把发型盖住了），开车的看不见人。
- **头像** `face-<皮肤>`：同一套模型的胸像，正面略偏 20°，透明底 128×128（游戏里显示 64～96 像素），和街上是同一个人。
- 档案顶部放大头像（96），名单行、居民总览的头像圈里放小头像（48）；没有图时退回原来的姓氏色块。

## 15. 一天的作息（D024）

### 15.1 时间
- 模拟仍按月结算；画面上把**一个月演成一天**：月初早上 6 点，月末晚上 10 点（`traffic.json: day`）。夜里不演。
- 顶栏日期胶囊两行：「1 年 11 月 / 上午 8 点」。暂停时钟停、人也停；两倍速时人走得也快。一天 60 秒（1 倍速），一个游戏小时约 3.75 秒。

### 15.2 日程（每人每天一张，按 id + 第几天固定随机）
| 身份 | 判定 | 一天 |
|---|---|---|
| 幼儿 | < 6 岁 | 不上街 |
| 学生 | 6～17 岁 | 县里有学校：6:48～7:30 去最近的学校，16:00～17:12 回家；没学校：一半人下午去广场 / 奶茶店 / 网吧玩 1～2 小时 |
| 上班族 | 有工作 | 6:30～8:00 去单位；17:00～18:30 下班，35% 先去吃的店（早餐铺 / 烧烤 / 火锅 / 超市 / 奶茶）待 0.7～1.5 小时再回家 |
| 赋闲 | `idle` | 9:30～11:00 出门逛一家店，1.5～2.5 小时后换一家，再 1～2 小时回家 |
| 待业 | 劳动年龄、没工作、不赋闲 | 8:30～10:00 去一个有岗位的地方（店铺 / 工业 / 公共 / 金融）问问，半小时到一小时后回家；40% 傍晚去吃的店 |
| 老人 | ≥ 60 岁 | 70% 早上 7:00～8:30 去广场 / 早餐铺 / 卫生院（有哪个去哪个，按这个顺序优先），1～2 小时后回家；40% 下午再遛一圈 |
| 没房子 | `homeId` 为空 | 不上街 |
- 去处在离出发点最近的 3 个候选里随机挑，人不会全挤一家。
- 每一趟沿道路走最短路（BFS），起点 / 终点是楼四周相邻的道路格；不通路就直接「到了」（不画）。到达时淡出，进的是店就冒一个金币（纯视觉，营业额仍按月算）。
- 新的一天开始时，还在路上的人直接到家，所有人重新排日程。

### 15.3 速度
- 速度 = 交通工具基础速度 × 道路倍率 × 个人差异（第 11.3 节），再乘**赶路倍率** = clamp(路长 ÷ (速度 × `trip.targetSeconds`), 1, `trip.maxHurry`)：一趟路尽量在 8 秒（1 倍速，约 2 个游戏小时）内走完，最多快 2.5 倍。步行 0.6 格/秒，4.8 格以内的路完全不加速。
- 有车的人路程 ≥ `trip.minDriveCells`（4 格）才按 `driveShare`（70%）开车，近路走路。

# 第二部分：核心玩法 v0.5（D026，2026-11-15，草案）

> 用户定方向：核心 = 满足居民心愿 → 幸福度 → 人口流动；加产业研究、招商谈判、特色街道指引、阶段目标、住房升级、施工、真实账目、开局县政府。
> 下面所有数值是初版，全部进配置表。2026-11-15 用户确认：名称用「县发展中心」、工期按大小 1～3 天、按四批开工。

## 16. 幸福度与人口流动

### 16.1 幸福度
- 界面上把「心情」改叫**幸福度**（字段仍是 `Resident.mood`，0～100）。**县城幸福度 = 全体居民平均**，顶栏笑脸显示它。
- 每个人的幸福度由若干**分项**组成（已有：工作、通勤、附近店铺、拥挤、环境、公共服务、买不到东西、税；新增：住房等级、心愿、口碑），模拟层每月把分项存进 `moodParts`，档案里能看到「为什么开心 / 不开心」。

### 16.2 迁入（幸福度的直接价值）
- 每天（= 每月结算）算一次「想来的人数」：`基础吸引 × f(县城幸福度) × (1 + 口碑)`，再受「有空房、有空岗（或来的人自带钱）」限制。
  | 县城幸福度 | f |
  |---|---|
  | < 30 | 0（没人想来） |
  | 30～50 | 0 → 1 线性 |
  | 50～70 | 1 → 2 线性 |
  | 70～85 | 2 → 2.5 |
  （2026-11-15 第二批调：原来 40 起步，开局 5 人幸福度 45 左右时迁入太少，县城长不起来）
- **口碑**：每满足一个心愿 +0.05，每天衰减 10%，上限 +0.5。每走一个人 −0.05。
- 来的人随机带一句理由，取自县里最突出的优点：「听说这儿的夜市很热闹」「亲戚说这儿好找工作」「这儿空气好」。

### 16.3 迁出与挽留
- 个人幸福度 **< 30**（`leaveMood`）→ 进入「**想走**」状态：家楼顶冒红色气泡，公告栏播「王建国想离开县城：上班太远、家附近没地方买菜」。理由 = 他扣分最多的两项。
- 挽留期 **3 天**（`leaveGraceDays`）。期间幸福度回到 **≥ 35** 就留下（公告「王建国决定留下来了」，口碑 +0.05）；到期还低就**全家**搬走。
- 取代原来的「心情 < 20 持续 3 个月」和「失业 6 个月就走」——失业本身就会把幸福度拉下来。

### 16.4 公告栏（左上角）
- 位置：顶栏下面、地图左上角，一行半透明白条，最新一条停留 4 秒后收起成一个小喇叭图标（有新消息时小红点）。点开 = 公告历史（复用大事记面板）。
- 播报：迁入 / 迁出 / 想走警告、心愿出现与达成、研究完成、施工完成、招商来人、特色街道凑成、阶段目标完成、建设资金不够；还有**玩法提示**（新玩家前几天轮播：「县城幸福度越高，外县来的人越多」「幸福度低于 30 的居民会想离开，点红色气泡看他为什么不开心」）。

### 16.5 大公示（屏幕中间）
- 触发：**有人来、有人走**、城镇升级、研究完成、招商签约。
- 来人卡片：头像 + 姓名 · 年龄 · 职业 +「从邻县搬到咱们县城了！」+ 理由；一家人一起来就一张卡显示全家头像。走人卡片灰色调 +「搬离了县城」+ 吐槽原因。
- 不暂停游戏，2.5 秒自动消失，点一下立刻关；同一天多张排队合并（「今天来了 3 位新居民」）。城镇升级是全屏庆祝 + 一句小剧情，点了才关（美术、文案原创，不用任何参考游戏的素材）。

### 16.6 人才引进（D030，2026-11-18）
- 自然迁入太慢（受「空房 × 空岗」双重限制），在「县发展中心」开**人才引进**页签：花建设资金主动从县外招人，**当场到账**，不用等每天那几个人。
- 规则：
  - 一次招 **6 人**，只要求**有空房**，不要求有空岗——来了自己去找工作。
  - 按学历分档定价：初中 ¥1,500 / 高中 ¥3,000 / 大专 ¥5,000（`economy.json` 的 `talentTiers`）。招的都是 22～30 岁。
  - 发起的这次是**同一档学历**的一批人（难度低的便宜，学历高的贵）。钱不够 / 没空房就按原因变灰。
  - **冷却 5 天**（游戏天 = 月），冷却期间按钮显示还要几天。
  - 开局就能用，不要求城镇等级。
- 自然迁入同时调快（16.2）：`immigrationRate` 2.0 → 3.5；**没有空岗位时也会少量来人**（按空房的一半算），来了先失业，慢慢自己找活。

## 17. 居民心愿
- 每人同时最多 1 个心愿。全县同时显示的心愿不超过 `max(3, 人口 ÷ 5)`，多的排队（优先：想走的人 > 老人小孩 > 其他）。
- 心愿只从**模拟层的真实数据**里产生：
  | 心愿 | 产生条件 | 满足条件 | 建议 |
  |---|---|---|---|
  | 吃饭 / 买东西 / 玩 / 其他 | 家附近（按交通工具算半径）没有这类店 | 半径内出现这类店 | 在他家 N 格内盖 X 类店（地图上高亮范围） |
  | 上学 | 家里有 6～17 岁孩子，附近没学校 | 附近有学校 | 研究 / 盖学校 |
  | 看病 | 60 岁以上，附近没卫生院 | 附近有卫生院 | 盖卫生院 |
  | 找工作 | 失业 ≥ 1 天，学历够的空岗为 0 | 找到工作 | 盖有 X 学历岗位的产业 |
  | 少走路 | 通勤超过舒适距离 | 通勤变短（家附近有岗位 / 修城市道路） | 修路或在他家附近建厂 |
  | 环境 | 家附近有污染 | 环境分 ≥ 0 | 种树、建广场 |
  | 买车 | 存款够、县里没车厂 | 买上车 | 研究 / 招商车厂 |
  | 住好房 | 存款够、房子等级低、没有更好的空房 | 住进更高等级 | 研究更高级住房 / 盖独栋 |
- 气泡画在他家楼顶（同一栋多人有心愿时显示一个气泡 + 数字）。点开：头像、心愿原话、建议（「在这里 6 格内盖一家早餐铺」+ 地图高亮）、剩余天数（默认 10 天）。
- 地图高亮（T538）：店 / 学校 / 卫生院心愿的卡片右上角「看范围」= 追踪这个人（T425），追踪期间地图上把他家沿路 N 格内的路铺浅蓝、他家描黄框，公告说一句「蓝色是他家沿路 N 格内的路，挨着这些路盖就行」。开始放楼后改画所放楼的覆盖范围（上一条）；心愿实现 / 过期后范围自动消失。
- 达成：幸福度 **+15**（一次性，之后正常回落）、口碑 +0.05、公告 + 爱心特效。过期没达成：幸福度 −5，过几天可能再提。

## 20. 招商引资（取代第 5 节）
- 每 3 天（3 个月）有 1～3 家外地企业发来**投资意向**（县城等级越高、营商环境越好来得越多），在公告栏提示，县政府「招商」面板里看。意向 7 天内有效。
- 每份意向写清楚：
  - **对方想建什么**：一种产业（可以是还没研究的，签约即解锁）。
  - **对方的要求**：地块大小、靠城市道路 / 河边、县里可用劳动力 ≥ N、营商环境 ≥ X。
  - **我们可以给的条件**（两条路线选一条，可以再附加让税）。**两条路线都会盖楼**：签约 → 玩家在地图上给对方划一块地 → 对方的厂（店）开工，建成后是私营企业（发工资、交企业税、利润归对方），这个产业从此解锁。区别在钱谁出（2026-11-19 用户确认，D032）：
    | 路线 | 我们付出 | 对方给的 | 条件 |
    |---|---|---|---|
    | **供地** | 一块地 | 交地时一次性**土地出让金**进财政；对方全额出钱施工 | 县里能招的工人 ≥ N（对方在本地招人） |
    | **补贴** | 一块地 + 交地时拨一笔补贴（造价 × `subsidyRate`），没有土地出让金 | 成功率 + `subsidyChanceBonus`；厂建成时对方带 N 名熟练工人 + 家属迁入（指定学历，有空房才住得下，住不下的不来） | 签约和交地时建设资金 ≥ 补贴 |
    | **让税**（附加） | 头 12 个月企业税减半 | 成功率 +20% | — |
  - **成功率** = 营商环境 × 系数 + 条件加成，封顶 90%。
- **签约流程（界面）**：
  1. 点某份意向的「供地签约」/「补贴签约」→ 弹**确认卡片**：哪家企业、建什么、我们拿到什么、付出什么、成功率。条件不够时按钮变灰，直接写「还差 4 个能招的工人」，不让人白点。
  2. 谈不成 → 弹**结果卡片**：说明最弱的一项（「对方嫌这儿没有城市道路」）和怎么补，不只在公告栏闪一下。意向作废。
  3. 谈成 → 关面板，镜头移到一块合适的空地（挨着路、离县城中心近），直接放好预览；顶栏提示「给××划一块地，按确定交地」。玩家可以点别处换位置，或按「稍后再选」。
  4. 没交地之前：县发展中心按钮亮红点，招商页顶上有「去选址 / 放弃」。一次只能有一份等交地的签约。
  5. 交地（按确定）时：供地收出让金；补贴扣补贴款（钱不够就盖不下，提示差多少）。之后照常施工（DESIGN 24）。
- **营商环境分**（0～100）= 道路覆盖 + 城市道路 + 港口 + 派出所 + 学历结构 + 可用劳动力 + 发展中心等级 − 税率惩罚。
- 成功率 = 营商环境 × 系数，封顶 85%。
- 结果按权重随机：
  | 结果 | 内容 |
  |---|---|
  | 工厂 | 免费送一座当前等级可用的工厂（玩家选位置） |
  | 品牌 | 送一家连锁店铺，口碑起点高 |
  | 投资款 | 财政 + 一笔钱 |
  | 人才 | 迁入几位高学历居民 |
  | 失败 | 只花了招商费，弹一句理由（"投资方嫌交通不方便"） |
- 失败理由要指向营商环境里最弱的那一项，告诉玩家下次该补什么。

## 11. 出行与交通工具（D022）

### 11.1 谁有车
- 开局全员 `walk`。每月结算第 4 步（居民状态更新）里，对每个 18～65 岁、有工作、还没有更好交通工具的人判断一次「买车」：
  | 交通工具 | 前提 | 价格 | 买的条件 | 每月概率 |
  |---|---|---|---|---|
  | 电动车 ebike | 县里有 ≥1 座摩托车厂 | 3,000 | 储蓄 ≥ 价格 × 1.5 | 1.5% |
  | 摩托车 moto | 同上 | 8,000 | 储蓄 ≥ 价格 × 1.5，月薪 ≥ 3,000 | 1% |
  | 汽车 car | 县里有 ≥1 座汽车厂 | 40,000 | 储蓄 ≥ 价格 × 1.2，月薪 ≥ 4,500 | 0.8% |
- 只往上换（步行 → 电动车 → 摩托车 → 汽车）；同时满足几档时直接买最好的那档，旧车不回收。
- 买车的钱：从储蓄扣，算进**最近一座对应工厂的产值**（企业税照常收）。记一条大事记。
- 厂全拆了：已有的车照开，只是没人能再买。
- 汽车每月油费 300（从可支配收入里扣，不进财政）；电动车、摩托车不计。
- 数值全在 `economy.json: vehicles`。
- 调参依据（支线 A 30 年快进，2026-11-14）：最初 8% / 5% / 3%、汽车 6 万时，盖摩托车厂 1 年有车率就到 45%、3 年 75%，而汽车 30 年一辆没卖出（储蓄平衡点约 6 万，够不着 7.2 万门槛）。调成上表后：第 1 年盖摩托车厂，1 年 8%、4 年 35%、10 年 44%、30 年 72%；汽车只有技术岗买得起，县里没学校时 30 年 7～14 辆。

### 11.2 车对模拟的影响
- 消费半径 = 这家店的 `radius`（没写用 `serviceRadius` 8）× 交通倍率：步行 1.0、电动车 1.5、摩托车 1.7、汽车 2.2。上班找工作的距离同理。
- 通勤惩罚 `commutePenalty` × （1 / 交通倍率）。
- 有车的人心情 +3（汽车 +5），一次性体现在每月心情目标里。

### 11.3 街上的表现（LifeLayer）
- 街上每个移动的东西都是一位居民：没车的走路，有车的按自己的车出现。**不再有匿名汽车**。
- 抽样比例：有车的居民出门时 70% 开车、30% 步行（短途也会走路）。
- 速度（格 / 秒，`config/traffic.json`）：
  | | 基础速度 | 土路倍率 | 城市道路倍率 | 桥 |
  |---|---|---|---|---|
  | 步行 | 0.6 | 1.0 | 1.0 | 1.0 |
  | 电动车 | 1.3 | 0.8 | 1.0 | 1.0 |
  | 摩托车 | 1.7 | 0.75 | 1.0 | 1.0 |
  | 汽车 | 2.2 | 0.45 | 1.0 | 1.0 |
  每人在基础速度上有 ±10% 的个人差异（按居民 id 固定，不每次随机）。在一格里按当前格的道路类型取倍率。
- 汽车现在也能开上土路（很慢），不再只走城市道路——修城市道路的意义就是「车跑得快 + 营商环境」。
- 图：电动车、摩托车、汽车各 3 种颜色；同一个人每次都是同一辆车（按 id 选颜色）。

## 12. 放置建筑（D022，修 D015 的朝向问题）
- 状态机：`空闲` →（底栏选建筑）→ `已选` →（点地块）→ `预览` →（确定）→ 盖下，回到 `已选`（方便连续盖同一种）；`预览` 里点别的地块 = 挪预览；点「取消」或底栏再点一次 = 回 `空闲`。
- 预览用真实贴图半透明显示，默认朝向按 D015 的规则（左下挨路 → L，右下挨路 → R，否则 L）；「换朝向」在 L/R 间切；没有 `_r` 图的建筑按钮灰掉。
- 放不下（重叠、越界、地形不许、钱不够）：预览染红，「确定」灰掉，下方一行小字说原因。
- 确定时把朝向一起交给 `TownModel.place(def, col, row, facing)`，直接锁定，不再等「第一次挨上路」。
- 道路（`flat`）跳过预览：点一下就铺，在 `已选` 状态下可以连续点。
- 浮动按钮跟着预览走，放在预览上方；靠屏幕边时自动挪到能看见的一侧。
- **覆盖范围**（T538）：预览店 / 学校 / 卫生院 / 派出所 / 广场时，从预览的门口沿路走 N 格以内的路铺浅蓝，范围内的住宅脚下描黄框；顶栏提示「沿路 N 格内（蓝色）能服务 X 栋住宅（黄框）」。N：店 = 这家店自己的 `radius`（D035，步行，有车的居民更远，提示里说一句），学校 10、卫生院 8、派出所 10、广场 6（和幸福度、心愿用同一组常量）。预览不挨路 → 不画，提示「这里不挨路，居民走不过来」。

## 14. 居民样貌（D023）

### 14.1 问题（2026-11-14 盘点）
- 街上只有 6 套外观：女性只有 1 套（马尾），老人只有 1 套（老爷爷），**没有小孩、没有老奶奶**；女性映射里还混着两套男性发型。5 岁小孩、70 岁奶奶上街都长成青年人的样子。
- 居民档案只有一个写着姓的色块，看不出是谁。

### 14.2 规则
- 一个人的样子由 **体型 + 外观编号** 决定，都从档案算出来，纯函数（`core/Appearance.ts`），不存档：
  | 体型 | 条件 | 外观数 |
  |---|---|---|
  | boy 男孩 / girl 女孩 | 0～17 岁 | 各 2 |
  | man 成年男 / woman 成年女 | 18～59 岁 | 各 3 |
  | oldman 老爷爷 / oldwoman 老奶奶 | 60 岁以上 | 各 2 |
  外观编号 = 按居民 id 哈希取模，同一个人一辈子在同一体型里永远是同一套；长大、变老时换体型，样子跟着变（档案和街上一起变）。
- 共 14 套外观，皮肤名 `<体型><编号>`，例如 `woman1`、`oldman0`。每套有固定的发型、发色、上衣、裤子、鞋子：
  - 小孩矮一截（约成人 0.75），头身比更大，背书包（男孩）或扎两个小辫（女孩）。
  - 青壮男：短发 / 偏分 / 寸头；青壮女：马尾 / 齐肩短发 / 长直发。
  - 老爷爷：灰白稀疏 + 拄拐 / 光头 + 老头衫；老奶奶：灰白短卷 + 碎花衫 / 灰发盘髻 + 开衫。
- **街上** `<皮肤>-front0/front1/back0/back1`（14 × 4 = 56 帧，大小不变）；骑车的人沿用 3 套骑手外观（头盔把发型盖住了），开车的看不见人。
- **头像** `face-<皮肤>`：同一套模型的胸像，正面略偏 20°，透明底 128×128（游戏里显示 64～96 像素），和街上是同一个人。
- 档案顶部放大头像（96），名单行、居民总览的头像圈里放小头像（48）；没有图时退回原来的姓氏色块。

## 15. 一天的作息（D024）

### 15.1 时间
- 模拟仍按月结算；画面上把**一个月演成一天**：月初早上 6 点，月末晚上 10 点（`traffic.json: day`）。夜里不演。
- 顶栏日期胶囊两行：「1 年 11 月 / 上午 8 点」。暂停时钟停、人也停；两倍速时人走得也快。一天 60 秒（1 倍速），一个游戏小时约 3.75 秒。

### 15.2 日程（每人每天一张，按 id + 第几天固定随机）
| 身份 | 判定 | 一天 |
|---|---|---|
| 幼儿 | < 6 岁 | 不上街 |
| 学生 | 6～17 岁 | 县里有学校：6:48～7:30 去最近的学校，16:00～17:12 回家；没学校：一半人下午去广场 / 奶茶店 / 网吧玩 1～2 小时 |
| 上班族 | 有工作 | 6:30～8:00 去单位；17:00～18:30 下班，35% 先去吃的店（早餐铺 / 烧烤 / 火锅 / 超市 / 奶茶）待 0.7～1.5 小时再回家 |
| 赋闲 | `idle` | 9:30～11:00 出门逛一家店，1.5～2.5 小时后换一家，再 1～2 小时回家 |
| 待业 | 劳动年龄、没工作、不赋闲 | 8:30～10:00 去一个有岗位的地方（店铺 / 工业 / 公共 / 金融）问问，半小时到一小时后回家；40% 傍晚去吃的店 |
| 老人 | ≥ 60 岁 | 70% 早上 7:00～8:30 去广场 / 早餐铺 / 卫生院（有哪个去哪个，按这个顺序优先），1～2 小时后回家；40% 下午再遛一圈 |
| 没房子 | `homeId` 为空 | 不上街 |
- 去处在离出发点最近的 3 个候选里随机挑，人不会全挤一家。
- 每一趟沿道路走最短路（BFS），起点 / 终点是楼四周相邻的道路格；不通路就直接「到了」（不画）。到达时淡出，进的是店就冒一个金币（纯视觉，营业额仍按月算）。
- 新的一天开始时，还在路上的人直接到家，所有人重新排日程。

### 15.3 速度
- 速度 = 交通工具基础速度 × 道路倍率 × 个人差异（第 11.3 节），再乘**赶路倍率** = clamp(路长 ÷ (速度 × `trip.targetSeconds`), 1, `trip.maxHurry`)：一趟路尽量在 8 秒（1 倍速，约 2 个游戏小时）内走完，最多快 2.5 倍。步行 0.6 格/秒，4.8 格以内的路完全不加速。
- 有车的人路程 ≥ `trip.minDriveCells`（4 格）才按 `driveShare`（70%）开车，近路走路。

# 第二部分：核心玩法 v0.5（D026，2026-11-15，草案）

> 用户定方向：核心 = 满足居民心愿 → 幸福度 → 人口流动；加产业研究、招商谈判、特色街道指引、阶段目标、住房升级、施工、真实账目、开局县政府。
> 下面所有数值是初版，全部进配置表。2026-11-15 用户确认：名称用「县发展中心」、工期按大小 1～3 天、按四批开工。

## 16. 幸福度与人口流动

### 16.1 幸福度
- 界面上把「心情」改叫**幸福度**（字段仍是 `Resident.mood`，0～100）。**县城幸福度 = 全体居民平均**，顶栏笑脸显示它。
- 每个人的幸福度由若干**分项**组成（已有：工作、通勤、附近店铺、拥挤、环境、公共服务、买不到东西、税；新增：住房等级、心愿、口碑），模拟层每月把分项存进 `moodParts`，档案里能看到「为什么开心 / 不开心」。

### 16.2 迁入（幸福度的直接价值）
- 每天（= 每月结算）算一次「想来的人数」：`基础吸引 × f(县城幸福度) × (1 + 口碑)`，再受「有空房、有空岗（或来的人自带钱）」限制。
  | 县城幸福度 | f |
  |---|---|
  | < 30 | 0（没人想来） |
  | 30～50 | 0 → 1 线性 |
  | 50～70 | 1 → 2 线性 |
  | 70～85 | 2 → 2.5 |
  （2026-11-15 第二批调：原来 40 起步，开局 5 人幸福度 45 左右时迁入太少，县城长不起来）
- **口碑**：每满足一个心愿 +0.05，每天衰减 10%，上限 +0.5。每走一个人 −0.05。
- 来的人随机带一句理由，取自县里最突出的优点：「听说这儿的夜市很热闹」「亲戚说这儿好找工作」「这儿空气好」。

### 16.3 迁出与挽留
- 个人幸福度 **< 30**（`leaveMood`）→ 进入「**想走**」状态：家楼顶冒红色气泡，公告栏播「王建国想离开县城：上班太远、家附近没地方买菜」。理由 = 他扣分最多的两项。
- 挽留期 **3 天**（`leaveGraceDays`）。期间幸福度回到 **≥ 35** 就留下（公告「王建国决定留下来了」，口碑 +0.05）；到期还低就**全家**搬走。
- 取代原来的「心情 < 20 持续 3 个月」和「失业 6 个月就走」——失业本身就会把幸福度拉下来。

### 16.4 公告栏（左上角）
- 位置：顶栏下面、地图左上角，一行半透明白条，最新一条停留 4 秒后收起成一个小喇叭图标（有新消息时小红点）。点开 = 公告历史（复用大事记面板）。
- 播报：迁入 / 迁出 / 想走警告、心愿出现与达成、研究完成、施工完成、招商来人、特色街道凑成、阶段目标完成、建设资金不够；还有**玩法提示**（新玩家前几天轮播：「县城幸福度越高，外县来的人越多」「幸福度低于 30 的居民会想离开，点红色气泡看他为什么不开心」）。

### 16.5 大公示（屏幕中间）
- 触发：**有人来、有人走**、城镇升级、研究完成、招商签约。
- 来人卡片：头像 + 姓名 · 年龄 · 职业 +「从邻县搬到咱们县城了！」+ 理由；一家人一起来就一张卡显示全家头像。走人卡片灰色调 +「搬离了县城」+ 吐槽原因。
- 不暂停游戏，2.5 秒自动消失，点一下立刻关；同一天多张排队合并（「今天来了 3 位新居民」）。城镇升级是全屏庆祝 + 一句小剧情，点了才关（美术、文案原创，不用任何参考游戏的素材）。

### 16.6 人才引进（D030，2026-11-18）
- 自然迁入太慢（受「空房 × 空岗」双重限制），在「县发展中心」开**人才引进**页签：花建设资金主动从县外招人，**当场到账**，不用等每天那几个人。
- 规则：
  - 一次招 **6 人**，只要求**有空房**，不要求有空岗——来了自己去找工作。
  - 按学历分档定价：初中 ¥1,500 / 高中 ¥3,000 / 大专 ¥5,000（`economy.json` 的 `talentTiers`）。招的都是 22～30 岁。
  - 发起的这次是**同一档学历**的一批人（难度低的便宜，学历高的贵）。钱不够 / 没空房就按原因变灰。
  - **冷却 5 天**（游戏天 = 月），冷却期间按钮显示还要几天。
  - 开局就能用，不要求城镇等级。
- 自然迁入同时调快（16.2）：`immigrationRate` 2.0 → 3.5；**没有空岗位时也会少量来人**（按空房的一半算），来了先失业，慢慢自己找活。

## 17. 居民心愿
- 每人同时最多 1 个心愿。全县同时显示的心愿不超过 `max(3, 人口 ÷ 5)`，多的排队（优先：想走的人 > 老人小孩 > 其他）。
- 心愿只从**模拟层的真实数据**里产生：
  | 心愿 | 产生条件 | 满足条件 | 建议 |
  |---|---|---|---|
  | 吃饭 / 买东西 / 玩 / 其他 | 家附近（按交通工具算半径）没有这类店 | 半径内出现这类店 | 在他家 N 格内盖 X 类店（地图上高亮范围） |
  | 上学 | 家里有 6～17 岁孩子，附近没学校 | 附近有学校 | 研究 / 盖学校 |
  | 看病 | 60 岁以上，附近没卫生院 | 附近有卫生院 | 盖卫生院 |
  | 找工作 | 失业 ≥ 1 天，学历够的空岗为 0 | 找到工作 | 盖有 X 学历岗位的产业 |
  | 少走路 | 通勤超过舒适距离 | 通勤变短（家附近有岗位 / 修城市道路） | 修路或在他家附近建厂 |
  | 环境 | 家附近有污染 | 环境分 ≥ 0 | 种树、建广场 |
  | 买车 | 存款够、县里没车厂 | 买上车 | 研究 / 招商车厂 |
  | 住好房 | 存款够、房子等级低、没有更好的空房 | 住进更高等级 | 研究更高级住房 / 盖独栋 |
- 气泡画在他家楼顶（同一栋多人有心愿时显示一个气泡 + 数字）。点开：头像、心愿原话、建议（「在这里 6 格内盖一家早餐铺」+ 地图高亮）、剩余天数（默认 10 天）。
- 地图高亮（T538）：店 / 学校 / 卫生院心愿的卡片右上角「看范围」= 追踪这个人（T425），追踪期间地图上把他家沿路 N 格内的路铺浅蓝、他家描黄框，公告说一句「蓝色是他家沿路 N 格内的路，挨着这些路盖就行」。开始放楼后改画所放楼的覆盖范围（上一条）；心愿实现 / 过期后范围自动消失。
- 达成：幸福度 **+15**（一次性，之后正常回落）、口碑 +0.05、公告 + 爱心特效。过期没达成：幸福度 −5，过几天可能再提。

## 20. 招商引资（取代第 5 节）
- 每 3 天（3 个月）有 1～3 家外地企业发来**投资意向**（县城等级越高、营商环境越好来得越多），在公告栏提示，县政府「招商」面板里看。意向 7 天内有效。
- 每份意向写清楚：
  - **对方想建什么**：一种产业（可以是还没研究的，签约即解锁）。
  - **对方的要求**：地块大小、靠城市道路 / 河边、县里可用劳动力 ≥ N、营商环境 ≥ X。
  - **我们可以给的条件**（选一种或组合）：
    | 条件 | 我们付出 | 对方给的 |
    |---|---|---|
    | **供地** | 在地图上划一块地给对方（像放建筑一样选位置） | 一次性**土地出让金**进财政；对方自己出钱施工，建成后是私营企业（发工资、交企业税），这个产业从此解锁 |
    | **补贴** | 一次性拨款 | 对方带来 N 名员工 + 家属（指定学历），直接迁入（要有空房） |
    | **让税** | 头 12 个月企业税减半 | 签约成功率 +20% |
  - **成功率** = 营商环境 × 系数 + 条件加成，封顶 90%。失败时说明最弱的一项（「对方嫌这儿没有城市道路」）。
- **营商环境分**（0～100）：城市道路覆盖、可用劳动力、学历结构、派出所、港口、税率、县城幸福度。县政府面板里有分项条。

## 21. 特色街道
- 判定：同一段连续道路两侧、彼此距离 ≤ 4 格的建筑凑齐组合（PRD 第 6 节五种）。
- **教玩家怎么凑**：
  1. 县政府里有「特色街道图鉴」：五种街道的组合、效果；凑成过的点亮。
  2. 放置预览时，如果这栋楼能让附近凑成或接近一条街，预览旁出提示：「再盖一家火锅店，这里就成『夜市一条街』了」。凑成会成的位置预览描绿边。
  3. 凑成时：街口立一块路牌、公告 + 大公示、图鉴点亮。
  4. 阶段目标里要求凑街，第一次时公告栏给一句引导：「打开县政府 → 特色街道图鉴，看看怎么凑」。
- 效果作用在真实数据上（营业额、幸福度、迁入），不是虚加的分数。

## 22. 环境与污染
- 每栋建筑的 `env`（已有）影响周围 3 格：工厂 −2～−3、矿场 −3、树 +1、广场 +2。住宅的环境分 = 周围之和，进幸福度分项。
- 地图上开「环境」视图时按格子染色（绿 → 红），放工厂时预览显示污染范围。

## 23. 住房等级
| 级 | 名称 | 住几人 | 怎么来 | 房租 / 月 | 幸福度 |
|---|---|---|---|---|---|
| 1 | 土坯农房 | 3 | 玩家盖（开局都是这个） | 200 | −5 |
| 2 | 砖瓦房 | 4 | 住户自己翻盖 | 300 | 0 |
| 3 | 自建小楼 | 6 | 住户自己翻盖 | 400 | +4 |
| 3 | 公寓楼 | 12 | 玩家盖（村口研究，人口 ≥ 10；或招商开发商） | 300 | +2 |
| 4 | 独栋 | 4 | 玩家盖 | 1,200 | +8 |
| 5 | 别墅 | 4 | 玩家盖（县级市） | 2,500 | +12 |
- **自家翻盖（1→2→3）**：研究过下一级，且这户人家存款合计 ≥ 翻盖费 × 1.5、心情 ≥ 50 → 满足条件后的月结算自动开工。**钱从住户存款里出**（付给施工，计入县里建筑业营业额并交税），占同一块地，施工期间照住（显示脚手架）。公告：「李秀兰家翻盖成了砖瓦房」。
- **搬家**：存款够、有更高级的空房 → 搬过去（已有换房逻辑扩展）。独栋、别墅专门吸引高收入和赋闲的人。
- 需要美术：5 级住房 × 2 朝向 + 脚手架 3 种尺寸。

## 24. 施工
- 除道路、树外，所有建筑盖下后先进入**施工**：工地 + 脚手架 + 进度条。工期：1×1 店铺 / 住宅 **1 天**，2×2 **2 天**，大型（汽车厂、港口等）**3 天**（用户确认，2026-11-15）。
- 钱在开工时扣；施工期间没有功能（不住人、不招工）；完工公告。招商企业的厂由对方出钱，工期一样。
- **画面**（2026-11-15 用户要求「塔吊到建成」的动画）：楼本身先不显示，换成工地图，按进度分三档——① 蓝白围挡 + 基坑 + 钢筋砖堆 → ② 混凝土框架 + 黄色脚手架 → ③ 整栋绿色安全网封顶；工地后角立一台塔吊，吊臂来回摆（4 帧，跟游戏倍速走，暂停时停）；塔吊顶上一条进度条。完工那一刻：撤掉工地，楼从矮一截弹起来（0.3 秒）+ 脚下一圈尘土散开。图：`docs/art/3d/construction.py`（1×1、2×2 两套）。

## 25. 真实账目
- **原则：每一分钱都有来处和去处，账能对上。** 县里的钱只有三种进出：县外进来（工厂外销、招商款、迁入者带来的存款）、流到县外（进货成本、油费、搬走带走的存款）、在县内转手。
- 每个主体一本账：
  | 主体 | 收入 | 支出 |
  |---|---|---|
  | 居民 | 工资（雇主付）、养老金（财政付） | 消费（付给店）、房租、个税、油费、买车、翻盖 |
  | 店铺 | 居民消费 | 员工工资、进货成本（营业额 × 成本率，流出县外）、营业税；剩下是利润 |
  | 工厂 | 外销产值（县外进来） | 员工工资、原料成本（流出）、企业税 |
  | 财政 | 各种税、土地出让金、招商款 | 建设、维护、公共岗位工资、养老金、研究费、补贴 |
- 店铺 / 工厂连续 3 天亏损 → 裁员；再亏 → 关门歇业（楼还在，公告提示），营业额回来后重新招工。
- 建筑详情显示真实账：营业额、工资、成本、税、利润。
- **现状问题（2026-11-15 查代码）**：私营岗位的工资是凭空发给居民的（不从店铺营业额里扣），店铺营业额交完税就消失了。所以钱只进不出：50 年快进财政 4,900 万。而且按配置，早餐铺每月营业额 1,440（120 人次 × 12 元），两名店员工资就要 5,600——按真实账目它每月亏 4,000 多。**做真实账目必须同时重调所有店铺的客单价 / 人次 / 工资。**
- 加一个守恒测试：每月「所有账户余额变化之和 = 县外流入 − 流出到县外」，差 1 元都算失败。

### 25.1 第一批实现记录（2026-11-15）

### 26.1 第三、四批实现记录（2026-11-15）
- **特色街道**（`progress.json: streets`）：每种建筑各一栋、沿路两两 ≤ 4 格即凑成（施工中的不算凑成，但放置提示会算上）。效果全部落在真实数据上：成员店过路客倍率（县外的钱）、周边 8 格住户幸福度分项「附近有 X」（学区只算有孩子的、青年街只算 18～35 岁）、网红打卡街每天口碑 +0.02。成员楼顶插对应颜色的小旗。县发展中心「特色街道」页签是图鉴（组合、效果、未研究的成员标红、凑成几条）。放置预览时顶上提示「再在附近盖一家 X，这里就成『Y』了」/「盖在这里能凑成『Y』！」。镇上的阶段目标加了「凑出 1 条特色街道」。

- **招商**（`progress.json: invest`）：每 3 天来 1～3 份意向（按等级的产业池），7 天有效。供地：对方要求县里有 N 个能招的工人；签约后去地图上选址（底栏自动选中、不花钱），盖下时收土地出让金（造价 60%，县外流入）、该产业永久解锁、建成后是私营（利润流出县外）。补贴：我们出造价 50%，对方送来 N 位熟练工人（要有空房）。附加让税：头 12 天企业税减半，成功率 +20%。成功率 = 营商环境 × 0.9（+ 让税），封顶 90%；失败说出最弱的一项。营商环境 7 项（城市道路、能招到的工人、学历、派出所、港口、税率、幸福度）在面板里有分项条。县城阶段目标加了「招商成功 1 次」。

**三个特殊规则**（其余都是普通店 / 房 / 厂，不用写代码）：
- **婚宴**（`wedding: 12000`）：居民结婚当月，如果县里有开着、有员工的大酒楼，就去离家最近那家办酒。花 min(12000, 两人存款合计 ÷ 2)，不到 12000 × 30% 就不办。这笔钱当月直接记进酒楼的账（营业额 / 成本 / 税 / 利润），财政已经结过账，所以税和县属利润直接进资金（和买车一样），守恒。大事记：「A 和 B 在大酒楼办了婚宴，花了 ¥x」。
- **幼儿园**：家里有 0～6 岁孩子、8 格内有幼儿园 → 幸福度分项「孩子上幼儿园方便」+5（`kindergartenMood`）；这家生孩子概率 ×1.5（`kindergartenChildMult`）。
- **老街**（`boostRadius: 6, boostMult: 1.5, buzz: 0.01`）：6 格内的店（含老街自己）过路客再 ×1.5，和特色街道的倍率相乘，几座老街取最大的；每月县城口碑 +0.01。老街先做 2×2；长条形（1×4）要等占地能随朝向转再说。

**美食街**：面馆 + 家常菜馆 + 大酒楼，成员店过路客 ×2，周边居民幸福度 +4。
