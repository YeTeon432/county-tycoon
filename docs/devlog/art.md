**mask 约定（给支线 D）**

两种 mask 的方向定义完全一样：**1 左上邻、2 右上邻、4 右下邻、8 左下邻**。
区别只在统计什么：

- 道路：某邻居**是路**，那一位为 1（两种道路互相算连通）。
- 水：某邻居**是陆地**，那一位为 1。这样 `water-0` 是纯水面（四面都是水），`water-15` 是四周全是岸的孤岛式水块（实际不会出现，但栅格完整）。

桥的帧名是 `bridge-gx` / `bridge-gy`：`gx` 方向指左上↔右下（和地块坐标 gx 一致），`gy` 指右上↔左下。
支线 D 判断桥该用哪张：看河的两个方向上哪个方向有陆地接过去。

**问题 / 返工过的**

1. 水面第一版每像素随机挑深青 / 墨青 / 天蓝，远看是一层噪点。改成只用一个低频暗斑 + 稀疏的 2 像素冷白波纹。
2. 桥第一版在 16 像素高的地块里塞了三层栏杆 + 桥板，糊成一片。改成「桥外水 / 栏杆 / 暗影 / 桥板」四层，每层 2~3 像素宽。
3. 农田第一版垄纹太碎。改成按 `gy * 6` 切成 6 条垄，每条内部再分「垄沟 / 垄背 / 受光」三段。
4. 山第一版是个等腰三角形，中间一条竖亮带，雪顶画到了山脚（山脊列表是从下往上排的，`rows[:5]` 取到了脚）。
   改成：每行独立算半宽（带侧肩 `shoulder`、边缘随机起伏）+ 中脊折线，左右两坡分别受光 / 背光；
   雪顶改取 `rows[-4:]`（列表末尾才是山顶）。
